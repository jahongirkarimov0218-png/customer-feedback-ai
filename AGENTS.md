# Customer Feedback AI Intelligence

Mijozlarning matnli fikrlarini (feedback) sun'iy intellekt yordamida chuqur semantik tahlil qiluvchi, sentiment, asosiy muammolar, 3 ta top insight va ustuvor yechimlar jadvalini ishlab chiquvchi production-ready Next.js SaaS platformasi.

## Ko'rsatmalar va buyruqlar

| Buyruq | Maqsadi |
|--------|---------|
| `npm install` | Bog'liqliklarni o'rnatish |
| `npm run dev` | Mahalliy dev-serverni ishga tushirish (http://localhost:3000) |
| `npm run build` | Production build qilish |
| `npm run test` | Testlarni ishga tushirish |

## Texnologiyalar
- **Next.js 14+ (App Router)**
- **TypeScript**
- **Tailwind CSS**
- **Lucide Icons**
- **Google Gemini API / OpenAI / Built-in Semantic Engine fallback**

## Autopilot ishlash tartibi
Sборка ведётся навыком `/autopilot`. Требования, спецификация и таски — в `.autopilot/`.
Прогресс — `.autopilot/dashboard.html`. Правило: требование из `manifest.md`
может снять только пользователь.

Если работа продолжается — скажи «продолжи автопилот»: состояние поднимется
из `.autopilot/state.js`, переспрашивать ничего не нужно.
